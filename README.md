## 📌 Project Overview

The Student Management System is designed to manage student information and academic records efficiently.

It provides features for:

- Student registration
- Student search
- Academic record management
- Attendance tracking
- Marks management
- Automatic grade calculation
- Pass/Fail evaluation
- Student performance analytics

## 🧮 Grade System

| Marks | Grade |
|------:|:-----:|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

### ✅ Pass Criteria

A student is considered *Pass* when:

- Marks are at least 40
- Attendance is at least 75%

Otherwise, the student is marked as *Fail*.

⚙️ Installation

Clone the repository:

git clone https://github.com/sunnythakursunny650-cell/Student-Management-System/edit/main/README.md

Go to the project directory:

cd Student-Management-System

Install the required packages:

pip install -r requirements.txt


---

▶️ Run the Application

Run the Streamlit application:

streamlit run app.py

The application will open in your web browser.
