# Student Management System

A Python-based Student Management System using SQLite Database.

## Features
- Add Student
- View All Students
- Update Student Details
- Delete Student Record

## Technologies Used
- Python 3.x
- SQLite3
- Object-Oriented Programming (OOP)

## Project Structure
- main.py
- student.py
- database.py
- students.db
